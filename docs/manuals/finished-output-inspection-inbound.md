# 成品产出清单、复检与入库操作手册

适用流程：批量任务与研发任务的产出登记、成品质检、结案审批、批准清单更正及成品入库。适用人员：产线管理员、质检人员、工单负责人和库管。

**当前可用入口**包括保存产出草稿、登记检验、送审、批准后发起清单更正及按批准清单入库。质检数量仅作定稿建议，差异不阻断保存、送审或批准；**固定已入基准、剩余范围快照及复检开始即暂停剩余入库仍待整改**；下方阶段表表达已确认的办理原则，不能据此认为所有场景已可在系统内完整办理。实施缺口见[本手册的当前限制](#当前限制)及[路线图](../roadmap.md#cq-01成品剩余复检整改)。

## 流程与职责

产线保存草稿 → 质检记录 → 产线管理员核对、引用记录并送审 → 工单负责人批准 → 形成正式清单 → 库管入库。

| 人员 | 负责的操作 |
| --- | --- |
| 产线管理员 | 填写计划内、计划外及实际新增报废；引用最新检验记录，核对并送审；需要时发起清单更正 |
| 质检人员 | 记录本次实际检查的合格数、不合格数及放行结论，保留时间、说明和凭据；不修改产出草稿或决定报废 |
| 工单负责人 | 作为结案审批末节点，审核提交的清单和检验依据 |
| 库管 | 核对当前有效批准清单与实物，确认实际入库 |

批准不等于已入库。当前计划内、计划外两类分别收齐后一次确认入库，不开放同一类别分次收货。任一类别已确认入库后，该类别的批准数量保持原值。

## 再次检验时，按哪个阶段办理

| 当前阶段 | 再次检验的处理 |
| --- | --- |
| 尚未送审 | 追加检验记录，管理员重新核对草稿 |
| 正在审批 | 先撤回或驳回，解除审批冻结后重新检验 |
| 已批准，尚未入库 | 开启更正及复检，重新核对、审批形成新版 |
| 部分已入库 | 仅重新办理剩余实物；已入部分及历史依据保留 |
| 全部已入库 | 属于在库质量处理，不再通过产出清单重新授予入库资格 |

部分入库或清单拆成计划内、计划外，不会自动要求复检。本表用于确实需要再次检查时选择办理路径。全部已入库后的在库质量处置尚未开放，不能按现有产出清单入口办理。

## 定稿时如何使用数量建议

质检明确放行后，全检按合格数、抽检按实际送检总数减样本不合格数提供本次建议。产线管理员仍按核实结果填写清单，保留原有说明及负责人审批，系统不因数量偏离建议拦保存、送审或批准，也不新增强制超建议说明或额外审批。

尚未入库时，系统提示计划内＋计划外与本次建议的差异。已有入库时，页面分别展示当前已入数量、本次建议和清单数量；当前已入量会随实际办理变化，不能把它当成固定历史基准。复检发起时固定I₀并形成累计建议S=I₀＋R仍待实施，当前页面不拼算累计建议。

检验原始数量、当时建议、实际定稿数量、引用版本及操作人员保留关联。最新记录必须明确放行，计划内上限、已入类别锁量继续校验；真正入库仍以有效正式批准量为依据，不能重复入库。

## 首次产出与入库

1. 产线管理员从生产任务打开“产出清单与结案”，核对收尾和物料安排，填写并保存“产出草稿”。
2. 在“质检记录”页签点击“前往成品质检”，由质检人员登记实际检查事实及结论。全检填写实际合格、不合格数；抽检填写样本合格、不合格数，并独立核实实际送检总数。填写真实检查时间、说明和凭据。
3. 产线管理员回到产出草稿，刷新检验记录，引用最新有效记录，核对计划内、计划外及实际新增报废后送审。不合格数量不会自动变为报废数量。
4. 审批完成后，在“批准清单与更正”查看当前有效版本。库管进入入库管理，分别办理生产流转入库和额外产出入库；实际收齐对应类别后确认。

## 批准后需要再次检验

现有入口路径：

**生产任务 → 产出清单与结案 → 批准清单与更正 → 发起清单更正 → 质检记录 → 前往成品质检 → 新增复检记录。**

1. 先在“批准清单与更正”核对两类产出的实际入库情况及当前有效清单，填写原因并发起清单更正。任务已经完成或终止，仍可查看结案信息并进入本窗口。
2. 按上述路径进入成品质检。未开启更正时，已批准任务不能直接新增检验；正在审批时，必须先由有资格的申请人撤回或审批人驳回。
3. 检验保存后，产线管理员返回草稿，引用最新记录、核对产出并重新送审。更正批准形成新清单，保留旧版及其检验依据。
4. 库管核对新版清单；已有待确认入库单引用旧版时，须刷新并保存新版后再确认。历史已确认入库记录仍关联当时使用的清单，不改挂新版。

找不到任务时，检查成品质检列表的“办理范围”：默认待检筛选不会显示已经放行的任务。切换“已有检验记录”或清空筛选；也可从任务的“前往成品质检”直接定位。

## 正式清单与历史版本

每次最终审批通过形成一版正式产出清单；更正通过后新增版本，不覆盖旧版。办理入库时采用当前有效版，查询历史时保留各版及其批准依据。

“正式”表示该版本已经批准，不表示以后不能更正，也不表示已经入库。检验记录、正式清单和实际入库是三份不同的事实，追溯时应核对入库单当时引用的清单版本及该版检验记录。

## 当前限制

- **复检冻结尚未完整实现。** 当前开始清单更正或打开检验表单，不等于系统已经阻止剩余入库；现行自动冻结仅覆盖更正在审且数量变化的类别。已确认目标是复检开始立即暂停全部剩余送检实物的入库资格，固定历史已入基准，再取得有效新批准依据。不能以现有弹窗中的暂停提示判断这一目标已经生效。
- **固定已入基准及剩余范围快照尚未实现。** 例如已入10、剩余全检合格1／不合格1时，当前只分别显示当前已入10与本次建议1，不将11显示为已有固定依据的累计建议。质检如实填写，不为使建议与清单相等而虚填已入数量。
- **在库质量处理尚未开放。** 全部已入库后发现质量问题，应保留原真实入库事实，不能通过修改产出清单、虚构冲销或只改出库备注表示新的质量处置。

已确认的范围、冻结和数量原则见[成品检验所有者文档](../../apps/api/src/modules/quality/docs/finished-inspections.md)，实现差异证据见[CQ-01](../documentation-conflicts.md#cq-01)，待办统一维护于[路线图](../roadmap.md#cq-01成品剩余复检整改)。本手册不表示待整改能力已上线或已经通过验收。
