# 成品产出清单、复检与入库操作手册

适用流程：批量任务与研发任务的产出登记、成品质检、结案审批、批准清单更正及成品入库。适用人员：产线管理员、质检人员、工单负责人和库管。本文说明当前办理方式，交付验证与用户验收状态见[路线图](../roadmap.md#成品质检与产出核对整改)。

## 流程与职责

产线保存产出草稿 → 发起并完成质检 → 产线核对、引用记录并送审 → 工单负责人批准 → 库管按授权分次入库。

| 人员 | 负责的操作 |
| --- | --- |
| 产线管理员 | 填写累计计划内、累计计划外及实际新增报废；引用检验记录，核对并送审；需要时发起清单更正 |
| 质检人员 | 明确开始首次检验或复检，记录本次检查合格数、不合格数及人工选择的结论，保留时间、说明和凭据；零产出专用核实须明确放行 |
| 工单负责人 | 作为结案审批末节点，审核清单和检验依据 |
| 库管 | 核对有效授权及实物，填写本次实际入库数量，选择新建或已有库存批次并确认 |

保留的是生产产出草稿；仓库不再保存一份待确认入库草稿。库管确认时一次形成已完成入库单、实际明细和库存流水。授权耗尽后不再出现在可入候选中，历史批准和入库依据仍可查询。

## 首次产出与入库

1. 从生产任务打开产出清单，核对收尾和物料安排，填写并保存产出草稿。首次检验需要已有保存的产出申报。
2. 进入成品质检并明确开始检验。全检和抽检均只填写本次检查的合格数、不合格数，检查总数由系统相加；抽检不填写整批量，也不按样本推算整批合格量。普通检验结论初始为空，数量或方式变化后需重新选择；零产出使用专用核实方式，确认 G/F 均为零并明确选择放行。登记真实检查时间、说明和凭据后保存。质检表单、确认和历史只核对检查事实，不计算产出数量差异。
3. 产线返回产出清单，在输入旁核对检验事实，明确引用适用的有效放行记录，保存累计计划内、计划外及实际新增报废后再送审。仅所引用记录为放行全检时，页面提示累计目标与该检验轮建立时已入库基准加合格数的差额；提示不自动替换产出输入，不合格数量不会自动变为报废数量。
4. 审批完成后查看批准清单及其可入授权。库管选择授权、填写本次数量，再选择目标批次并确认；剩余授权可以继续分次办理。

计划内、计划外表示产出的授权类别，同一库存批次可以接收两类授权，也可以接收同产品其他任务的合法入库。已有目标必须是相同成品、相同单位且状态允许入库。物料采用相同归批方式，但还必须是相同物料精确版本；原采购和补购的归属仍随明细保留。

## 部分入库后更正或复检

| 当前阶段 | 再次办理方式 |
| --- | --- |
| 尚未送审，本轮检查已完成 | 从成品质检详情开始复检，完成后由产线重新核对草稿 |
| 本轮检验中，尚未提交结果 | 继续填写本轮结果，不重复发起复检 |
| 正在审批 | 先撤回或驳回，解除审批冻结后重新办理 |
| 已批准，尚未入库 | 数量或类别更正从产出清单办理；需要重新检查则从成品质检开始复检，再核对、审批 |
| 部分已入库 | 只重新办理剩余实物；已入事实、类别及历史依据保持原状 |
| 全部已入库，当前没有新增剩余实物 | 旧授权已经耗尽，不能发起剩余复检；在库质量问题不通过更改产出清单处理 |

需要复检时，在成品质检详情选择“开始复检”，填写原因并核对影响范围。确认成功立即开始新轮并暂停旧剩余授权，随后直接填写检验结果，不需要再点击一次开始，也没有额外的复检申请审批。产出清单的质检入口只负责定位该任务，不直接发起复检。待办按当前办理状态组织；即使上一次记录是放行，新轮仍会出现在当前待办中。

建立新轮时固定本任务历史已入基准，页面称“本轮建立时已入库”；开始更正或复检会暂停旧轮剩余授权。即使仓管保留了旧页面，也不能继续消费旧授权。关闭结果表单只是退出或放弃本地填写，已开始的检查和暂停状态继续保留，可再次进入继续填写。已开始的检验不能直接取消更正；取消其他可取消的更正、撤回或驳回都不会重新激活旧轮。需要继续办理时取得有效的新批准依据；已经要求复检时不能通过取消再重开而沿用更早的检查。

本轮保存为待复检或不放行后，若仍符合剩余实物和来源资格，可在成品质检再次开始下一轮；不要求先退出整个清单更正。首次待检、正在检验、已记录与正在审批对应的下一步不同，以页面当前资格和阻断原因提示为准。

更正中若确有新增剩余实物，产线保存增加后的累计目标，再由质检核对该剩余范围。可复检范围按来源历史真实已入与当前申报判断，不按库存批次的当前余额判断；不能把已经入库的旧实物重新纳入剩余检查。

若只是核对未执行数量或类别，可以引用仍适用的已有检验记录；实际剩余送检范围或质量情况变化时，应明确开始新的检查。检查只包含尚未入库的实物，不把历史已入数量再次填入送检数。已确认库存批次的归并、转移和在库质量处置不属于这里的更正功能。

例如初次计划内100、计划外20，已经按计划外入库20。重新核对累计总量为100，输入累计计划内80、累计计划外20；新授权只有计划内80。后续80可以分几次入原库存批次，也可以进入新批次，原20的入库明细与依据不变。

## 检查事实与实际授权

Quality 只记录 G/F、自动计算检查总数并保存明确结论，不生成本次放行量或累计建议量。抽检样本结果不代表整批合格数量，页面不显示抽检合格率或整批量差异。实际入库只按当前有效批准授权办理。

仅 Production 定稿引用放行的全检记录时，比较累计计划内与计划外目标之和，与**该检验轮建立时已入库计划内＋计划外＋本次检验合格数 G**的差额。例如原检验轮建立时已入 20、全检 G=80，累计目标 100 则差额为零；随后再入 30、纯清单更正沿用这条检验时，提示仍按原检验轮已入 20 加 G=80 核对，不改用新定稿轮基准 50。抽检和零产出核实不作该整批数量比较。

全检放行后的定稿差异仅作提示，不限制产线最终定稿数量，也不因偏离自动增加强制说明或审批。累计计划内、计划外分别不能低于各自历史已入量，计划内不能超过任务计划；明确放行、负责人审批及实际入库不超过有效剩余授权继续校验。

## 查询与追溯

成品质检列表按工单分组、按任务办理，分组摘要只覆盖当前页。“待检／待复检”用于当前工作，“已有检验记录”用于历史查询，两者可以重叠。尚未保存产出草稿的任务需要先到产出清单保存，可在全部任务范围查看；审批中或纯更正沿用适用放行依据的任务不列为待检。当前轮状态、最近历史结论与产出清单实际引用的依据分别核对；历史放行不表示当前可以入库。

产出核对与检验依据同时展示，检验历史和批准清单单独查看。标为最新的批准版本仍可能已暂停、被替代或没有剩余额度；应以当前执行资格判断是否可入库，不能仅看版本是否最新。取消清单更正也不表示旧授权恢复。

从产出跳转同一任务质检时，未保存内容可选择“保留填写并前往”或“保存并前往”。各页输入保留在当前会话的标签缓存中；返回会刷新资格和版本。若期间依据变化，可打开“核对并保留填写”，逐项比较服务端与本地的计划内、计划外、新增报废、检验引用、产出说明和物料安排，确认后保留本地输入；也可明确放弃并重新加载。该确认不会自动保存、送审或换用新检验，仍需在核对区明确采用适用记录。明确关闭或更换任务会提示处理未保存输入；硬刷新不保留这些本地草稿。

查询库存批次可看到进入该批次的各次入库明细；查询入库单可看到每条明细实际进入哪个批次。成品明细关联执行授权，再关联当时的批准版、检查记录及生产任务。新版批准不会改挂旧入库事实。

批次号是库存批次身份，入库单号是一次交接记录，两者不要求一一对应。一个批次混合多个来源后，可以追到来源集合；单靠入库历史不能判断后来某次领用精确消耗了哪一个来源。

## 当前边界及规则来源

已入库质量冲销、库存批次间事后合并／转移、仓管拒收和差异账本尚未开放。保留真实事实，不通过修改旧明细或备注代替新的库存处置。
