# 成品产出清单、复检与入库操作手册

适用流程：批量任务与研发任务的产出登记、成品质检、结案审批、批准清单更正及成品入库。适用人员：产线管理员、质检人员、工单负责人和库管。本文按已确认的分次入库规则说明办理方式；本次实施的验证及用户验收状态以[路线图](../roadmap.md#成品物料入库统一整改代码核对清单)为准。

## 流程与职责

产线保存产出草稿 → 发起并完成质检 → 产线核对、引用记录并送审 → 工单负责人批准 → 库管按授权分次入库。

| 人员 | 负责的操作 |
| --- | --- |
| 产线管理员 | 填写累计计划内、累计计划外及实际新增报废；引用检验记录，核对并送审；需要时发起清单更正 |
| 质检人员 | 明确开始检验，记录本次实际送检总数、合格数、不合格数及放行结论，保留时间、说明和凭据 |
| 工单负责人 | 作为结案审批末节点，审核清单和检验依据 |
| 库管 | 核对有效授权及实物，填写本次实际入库数量，选择新建或已有库存批次并确认 |

保留的是生产产出草稿；仓库不再保存一份待确认入库草稿。库管确认时一次形成已完成入库单、实际明细和库存流水。授权耗尽后不再出现在可入候选中，历史批准和入库依据仍可查询。

## 首次产出与入库

1. 从生产任务打开“产出清单与结案”，核对收尾和物料安排，填写并保存产出草稿。
2. 进入成品质检并明确开始检验。全检填写实际合格、不合格数；抽检填写样本合格、不合格数，并独立核实实际送检总数。登记真实检查时间、说明和凭据。
3. 产线刷新检验记录，引用适用的有效放行记录，核对累计计划内、计划外及实际新增报废后送审。不合格数量不会自动变为报废数量。
4. 审批完成后查看批准清单及其可入授权。库管选择授权、填写本次数量，再选择目标批次并确认；剩余授权可以继续分次办理。

计划内、计划外表示产出的授权类别，同一库存批次可以接收两类授权，也可以接收同产品其他任务的合法入库。已有目标必须是相同成品、相同单位且状态允许入库。物料采用相同归批方式，但还必须是相同物料精确版本；原采购和补购的归属仍随明细保留。

## 部分入库后更正或复检

| 当前阶段 | 再次办理方式 |
| --- | --- |
| 尚未送审 | 开始新的检查办理，产线重新核对草稿 |
| 正在审批 | 先撤回或驳回，解除审批冻结后重新办理 |
| 已批准，尚未入库 | 发起清单更正，需要时重新检验，再核对、审批 |
| 部分已入库 | 只重新办理剩余实物；已入事实、类别及历史依据保持原状 |
| 全部已入库 | 旧授权已经耗尽；在库质量问题不通过更改产出清单处理 |

开始更正时固定本任务历史已入基准，暂停旧轮剩余授权。即使仓管保留了旧页面，也不能继续消费旧授权。已开始的检验不能直接取消更正；取消其他可取消的更正、撤回或驳回都不会重新激活旧轮。需要继续办理时重新进入更正流程，取得有效新批准依据；已经要求复检时不能通过取消再重开而沿用更早的检查。

若只是核对未执行数量或类别，可以引用仍适用的已有检验记录；实际剩余送检范围或质量情况变化时，应明确开始新的检查。检查只包含尚未入库的实物，不把历史已入数量再次填入送检数。已确认库存批次的归并、转移和在库质量处置不属于这里的更正功能。

例如初次计划内100、计划外20，已经按计划外入库20。重新核对累计总量为100，输入累计计划内80、累计计划外20；新授权只有计划内80。后续80可以分几次入原库存批次，也可以进入新批次，原20的入库明细与依据不变。

## 数量建议与实际授权

质检明确放行后，全检按合格数、抽检按实际送检总数减样本不合格数提供本次建议。累计建议使用**被引用检验实际开始时的已入基准＋该次检查建议**。即使后续又有入库，只要沿用同一条检验记录，累计建议就不重新增加。

例如某次检查开始时已入20、剩余建议80，累计建议始终为100。随后又入30，仅更正定稿并沿用这条检查，当前新授权基准是50，但累计建议仍是100，不能改成50＋80＝130。

数量建议只作差异提示，不限制产线最终定稿数量，也不因偏离建议自动增加强制说明或审批。累计计划内、计划外分别不能低于各自历史已入量，计划内不能超过任务计划；明确放行、负责人审批及实际入库不超过有效剩余授权继续校验。

## 查询与追溯

查询库存批次可看到进入该批次的各次入库明细；查询入库单可看到每条明细实际进入哪个批次。成品明细关联执行授权，再关联当时的批准版、检查记录及生产任务。新版批准不会改挂旧入库事实。

批次号是库存批次身份，入库单号是一次交接记录，两者不要求一一对应。一个批次混合多个来源后，可以追到来源集合；单靠入库历史不能判断后来某次领用精确消耗了哪一个来源。

## 当前边界及规则来源

已入库质量冲销、库存批次间事后合并／转移、仓管拒收和差异账本尚未开放。保留真实事实，不通过修改旧明细或备注代替新的库存处置。
