## 使用规则

- 表的完整字段定义只在对应主题章节维护；跨表计算和事务规则集中在规则章节。
- `inventory_transaction` 始终是库存数量唯一事实来源，`production_item_demand` 始终是生产需求唯一事实来源。
- 标记为“待决策”的补料、质量、返工或流转能力不得据草案提前实施。
- 本目录与其他数据库章节共同受上级 [数据库设计总览](../README.md) 约束。
