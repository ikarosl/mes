# ADR-0024：质量补单分配依据的人工更正

状态：Superseded，由 [ADR-0025](0025-supplement-receipt-line-basis.md) 完整取代。本文保留分配引用更正方案的选择理由；当前补单关联到货明细，不再提供该命令。当前规则见 [Procurement 采购订单](../../apps/api/src/modules/procurement/docs/purchase-orders.md)，实施及验收状态见[路线图](../roadmap.md)。

## 选择理由

质量补单已有自身到货后，不能通过取消重建纠正误选的退回分配。新增“失效”状态不能表达正确依据，也无法解决已发生实物的追溯。补单来源用于解释采购决定，不提供仓库执行授权；在固定原采购行和原到货明细内，人工纠正分配引用不会转移物流数量。

这是一项明确的业务纠错能力，采购人员可以办理，不需要管理员专属角色或额外审批。草稿也可以纠正同次到货内误选的分配，无需仅为这一处引用取消重建。来源轮次被替代仍不自动要求人员更正。

分配 ID 表达具体依据，不表示永远属于最新轮次。质量退回已执行后，新定稿只处理剩余实物，可能不再生成质量退回分配；原实际退回及其补发原因仍由旧 ID 追溯。因此新建／主动改选核验当前有效或真实已退资格，已保存引用继续办理核验来源身份及未作废，不以 `superseded` 一刀切阻断下单。

## 决策

1. 草稿、已下单、已结束的质量补单允许逐行更正同次到货内的质量退回分配，已有自身到货不构成阻断；已取消单不再更正。普通草稿编辑仍只调整数量与备注，分配引用走专用更正命令。
2. 直接更新补单行的 `origin_allocation_id`。原采购行、原到货明细、建单说明、供应商、物料、采购数量、主行状态及物流事实保持不变。
3. 新选择仍须满足同源身份、未作废及质量退回依据资格。权限授予采购人员，不代表可以绕过来源约束。
4. 更正前后引用及原因通过现有全局操作日志追溯，与写入同事务；不建立独立关联历史表。业务查询只按当前保存的分配引用匹配，旧分配 ID 精确反查不再命中已更正行。同次到货、同补因的相关补单汇总保持完整。
5. 不开放跨到货、跨原采购行换绑，不修改不可变分配、实际入退或恢复旧仓库授权。

## 取代范围

本决策仅取代 [ADR-0023](0023-supplement-source-and-receipt-ownership.md) 中质量补单的分配引用不可人工更改、无更正入口及草稿同次到货内误选分配只能取消重建的限制。原采购及原到货身份固定、普通草稿编辑保留来源、创建与继续办理资格分离、超量不分走物流、质量独立新到货及来源替代不自动改变采购的规则继续有效。
