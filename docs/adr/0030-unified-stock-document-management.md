# ADR-0030：按库存对象统一出入库单据管理

状态：Accepted，独立实验分支。设计获批不代表用户验收或正式测试通过。

## 页面与事实边界

仓储以物料／成品及入库／出库组织统一主单列表和精确主单详情，创建及办理仍分派到采购、生产领退料、成品产出和其他单各自的能力。公共主单负责分页、排序和权限范围，业务来源只用于必要筛选和当前页展示；不引入第二套单据总表或全量拉取各业务列表后合并。

主单固定一种库存对象类型。同一其他单可含多个物料精确版本或多个成品，但不能混合物料与成品；本决定取代 ADR-0020 所属库存设计中允许其他单混合两种对象的范围，六种业务场景及来源所有权保持不变。字段、来源组合、数量和不可变约束由 [Inventory 数据库](../../apps/api/src/modules/inventory/docs/database/inventory-ledger-and-inbound.md)唯一维护。

## 编号与定位

所有入库共用一个平台日编号类型，所有出库共用另一个类型，物料与成品不拆计数。单号仅标识单据，场景由方向、对象类型和来源类型共同解释，不解析前缀决定业务行为。该决定取代 ADR-0017 中出入库按业务场景分配编号类型的范围，其余北京自然日、事务取号、不回收编号等约定继续由[业务编号](../../apps/api/docs/business-numbering.md)维护。

库存流水保存直接记账主单 ID 与单号快照，同时保留真实来源明细引用，避免前端以明细 ID 搜索或把单号链接到整个库批。快照不替代事实外键、来源资格或目标接口鉴权。上游采购、到货、产出、需求及分配仍沿真实关联追溯，不固化为混用语义的通用来源单号。具体字段及守卫归 Inventory，路由、草稿和跨页定位归[管理端路由](../../apps/admin-web/docs/route-dialogs-and-tabs.md)。

## 人工结束到货入库

保留 ADR-0028 的独立办理及无数量授权方案，增加到货行人工结束／恢复入库。开关改变没有采购、检验、数量或补单门槛；结束后禁止新增入库，其余业务独立。当前状态、版本及通用审计保留，不建立专用开关历史。完整语义由 [Procurement](../../apps/api/src/modules/procurement/docs/receipts.md#人工结束与恢复入库)维护。

## 实验与升级边界

本次允许丢弃指定测试环境的数据，不要求转换旧混合单及旧测试库存事实；使用新建独立空实验库验证，原数据库不自动清理。追加成对 migration，并在不支持转换的非空数据下拒绝执行；不修改基线或既有登记。实施后的测试库仍按后续迁移约定升级，迁移细节及失败恢复由[迁移安全](../../packages/database/docs/migration-safety.md)维护。

正式测试遵守[交付阶段](../testing-strategy.md)。本轮清理被替代代码及专属历史测试；高重要性覆盖在原位置保留 TODO 文字，待明确测试授权后恢复，不作为通过结果。
