# ADR-0018：外购物料按实际确认成单

状态：Accepted。用户已批准跨供应商合单；实施及验收状态见[路线图](../roadmap.md)。

## 选择与理由

外购物料入库单记录一次仓库实际确认，供应商属于各条采购来源。一次确认允许来自不同供应商、采购单、到货单和正式清单的有效分配，生成一张入库单并原子记账，不增加操作批次主单或按供应商自动拆单。当前轻量 MES 不承担供应商结算或对账凭证职责，供应商不作为实际确认的分单边界。

每条实际入库明细继续绑定当时的到货行、实收修订、检验记录、正式分配与目标库存批次。供应商稳定身份沿采购来源解析；确认时的供应商名称由入库明细保留，主单供应商摘要由明细汇聚，不再保存唯一供应商。字段与历史名称规则由 [Inventory 数据库](../../apps/api/src/modules/inventory/docs/database/inventory-ledger-and-inbound.md)维护。

## 保留的边界

- 仅放宽 `purchased` 外购物料入库的供应商限制，不开放采购与成品混合确认、跨到货合并检验或新的采购来源类型。
- 每个供应商及每条来源继续通过服务端资格校验；逐条版本、质量、当前轮、按分配汇总的余量、目标身份及数量上限保持有效。任何明细失败时，整次确认回滚，审计和幂等仍在同一事务。
- 界面按到货组织核对，可继续显示供应商分区；分区不形成写入限制，也不能静默扩大选择或丢弃草稿。
- 归入同一库存批次后，系统保留入库来源集合，不约束或推算后续领料消耗其中哪次到货、哪家供应商的份额。原有库存余额与领料数量校验不变。

## 取代范围

仅取代 [ADR-0015](0015-unified-quality-quantity-semantics.md) 和 [ADR-0016](0016-inbound-authorizations-and-stock-batches.md) 中“一次采购入库同供应商”的限制。其余质量、授权、采购归属、退回及库存事实不变量继续有效。

来源校验归 Procurement，实际入库和名称快照归 Inventory，Quality 继续提供不可变检验依据。当前契约见 [Inventory 公开能力](../../apps/api/src/modules/inventory/docs/public-contracts.md)，交互规则见[采购入库](../../apps/admin-web/docs/procurement-inbound.md)。
