# ADR-0009：研发轮次结案、产出处置与物料余量

状态：Accepted。结案职责由 [ADR-0011](0011-task-closeout-output-list-and-finished-goods-inbound.md)细化，任务用料及无工序研发由 [ADR-0014](0014-task-material-policy-and-output-inspection.md)细化。当前完整流程见 [Production 业务流程 §19.1](../../apps/api/src/modules/production/docs/business-workflow.md#191-研发轮次结束与产出处置)，状态、事实及命令见[结案设计](../../apps/api/src/modules/production/docs/database/production-termination.md)。

## 背景

研发在同一任务内可能使用同一物料的多个版本；结束试制后也可能使用新成品、新工单继续下一轮。旧轮次的可用产出、报废和物料余量必须据实保留。工序报废补料会生成额外需求和补产授权，因此不能直接用于已经决定停止的研发轮次。

## 决策

1. 各轮使用独立成品及工单，旧需求、领料、产出和库存继续归原轮；不复制旧事实承接下一轮，也不把旧轮的待入库产出转给新成品。研发不要求 BOM 或工序，可独立手工提出精确物料版本需求。
2. 任务执行结束、结案批准、工单终态与实际入库分别表达。实际执行过的任务先据实收尾、核对产出并审批，驳回或撤回不恢复已关闭需求、工序或真实退料。仅决定停止生产不能冒充先审批后生效的日常需求纠错。
3. 结案报废只处理尚未入库的本轮产出，不自动补料、补产或写库存，也不重复扣已领原材料；报废记录不是销毁证明。已有来源须去重，不把普通产出的报废改作额外产出。
4. 可用产出依据批准清单独立入库；零可用量不制造零量入库。正常与额外产出分别保留身份及独立批次；结束生产不自动记账，旧工单终态不妨碍原批准产出继续办理。
5. 物料余量由人员实核，不能按成品差额乘 BOM 倒推耗用、退料或损耗。未确认出库只处理需求与预留；已领可退部分沿原版本、原批次回公共库存，不恢复需求履约。损坏独立记录且不自动补料，额外需求另行提出。

## 所有权与实施边界

Production 所有研发结案和产出处置，Product 所有成品与物料版本，Quality 所有检验及放行，Inventory 所有唯一库存事实。复用现有生产和入库能力，不建立独立研发子系统、现场实时耗用账本、报废库或通用库存报废流程。

当前模块文档维护研发轮次关联、逐项收尾、审批与入库的完整规则；本 ADR 保留选择理由及历史边界，不替代验收。未完成事项统一见[路线图](../roadmap.md)。
