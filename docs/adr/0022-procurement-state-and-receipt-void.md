# ADR-0022：采购跟进状态与到货登记作废

本 ADR 涉及补单承接、分配采购归属及其取消／继续办理资格的条款，在 [ADR-0023](0023-supplement-source-and-receipt-ownership.md) 明确范围内被取代；其余业务边界继续有效。

状态：Accepted。采购结束／恢复和到货整单作废边界已批准；实施、用户验收及正式测试状态见[路线图](../roadmap.md#采购跟进状态与到货作废)。字段、接口及事务由[采购订单](../../apps/api/src/modules/procurement/docs/purchase-orders.md)、[到货处置](../../apps/api/src/modules/procurement/docs/receipts.md)和[采购数据库](../../apps/api/src/modules/procurement/docs/database.md)维护。

## 背景与选择

采购行状态表达人员是否继续跟进采购，实收到货、检查、正式分配和实际入退分别表达物流事实。采购结束不承担整单审批或财务结案职责，不需要在所有行结束后再增加一次主单确认。

采购人员只填写结束原因，不选择系统计算的结束类型。物流数量继续服务人员核对，不驱动采购状态，也不作为结束命令的跨模块资格依赖。到货误登记则需要独立作废路径，不能通过更正为零冒充登记无效，也不能用采购取消清除真实交接。

采购跟进只需要当前状态，不建立专属切换历史及详情时间线；动作原因和责任通过项目已有的通用操作日志审计。`production_batch_closeout_action` 绑定生产收尾根及生产事项，不是跨业务状态日志，采购不复用该表。到货作废与原登记共享同一业务身份、至多发生一次，没有独立生命周期，因此以到货主表的专门字段保存作废状态和责任，以主单版本仲裁更新；通用日志用于审计，不能代替业务状态。

## 决策

1. 已下单采购行由人员执行结束或恢复跟进，两个动作均填写原因。最后一个进行中行结束时主单汇总为已结束；已结束主单中任一行恢复后，主单同时恢复为已下单。主行状态、版本更新和成功审计在同一事务内完成。
2. 整单结束批量处理剩余进行中行，不要求先逐行结束。已经结束的行不重复更新。恢复某一行不恢复其他行。
3. 每次结束、恢复及整单取消将原因、操作者和目标写入通用 `operation_logs`，不额外保存采购行切换历史或物流快照。恢复表达新的采购决定，不复活历史到货授权，不改变实际入退或检验事实。
4. 草稿可以整单取消；已下单采购只有满足无自身到货和承接事实的条件时才可取消。已取消为终态，不允许通过恢复行重新生效。草稿及已取消主单不开放行结束或恢复。
5. 到货、质检、定稿、入库和实际退回不自动结束或恢复采购。结束采购不停止既有到货的合法处理；新增到货仍要求采购行进行中，人员先恢复再登记。
6. 到货整单作废用于误登记、重复登记或身份录错。所有到货行均无实际入库和实际退回、且无仍有效的关联补单依赖时才允许办理，任一行不满足则整单不执行。已检验或已定稿本身不构成阻断。
7. 到货主单保存作废标记、原因、人员和时间，具备创建／修改审计和乐观版本；原登记字段冻结。作废只允许有效到作废的一次性转换，不允许恢复或改写作废依据。整单作废收回未执行授权并终止未完成检验，保留原登记和已完成检查；作废后不能继续办理该到货的业务命令或将其作为新补单依据，历史仍可追溯。采购主行状态不随作废自动变化。
8. 关联补单必须先由人员取消或更正，再作废到货；已取消补单的历史引用保留。非取消状态的补单仍构成依赖，不能以结束采购代替解除真实来源。已绑定补单的承接纠错另行设计，本决策不批准自动解除或迁移归属。
9. 货确实到过、后来不再需要，办理拒收及实际退回。已有实际入库或退回的到货不提供简单整单作废，已执行历史不删除、覆盖或迁移。

## 取代范围与保留边界

本决策取代 [ADR-0013](0013-procurement-source-and-stock-boundaries.md) 第 5、9 条中按物流数量提供采购关闭资格的规则，以及第 9、11 条中以专属关闭证据表达采购结束且不允许人工恢复的限制。采购跟进状态与通用操作审计分开维护，实际物流和检验事实不可覆盖的原则继续有效。

到货主表整体禁止更新的约束，在本决策范围内由原登记字段冻结与一次性作废转换取代。该取代只适用于到货主表的作废状态、修改审计和版本；原单号、采购归属、交接时间／凭据、备注及创建依据不能改写，实收修订、正式清单／分配、真实物流、检查和库存事实继续遵守各自不可变规则。正式下单后的供应商、物料身份、计划量及需求来源冻结规则保持；采购取消仍按历史自身到货／承接事实判断，不因到货作废自动恢复资格。未执行补单归属更正、逐行作废及在未恢复采购行时登记新到货均不属于本次实施范围。
