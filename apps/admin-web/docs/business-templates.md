# 系统模板管理

模板的内容、列填写规则、场景默认、权限及并发边界由 [Template](../../api/src/modules/template/docs/template-scenes.md)维护；JSON 表格格式由 [utils](../../../packages/utils/README.md#json-表格)维护。本文只补充设计草稿及业务表单的交互边界。

## 编辑与使用边界

表格尺寸输入在明确确认后才改变草稿；扩展保留已有内容，缩减从末尾移除行列，涉及列名或非空单元格须确认。重新打开按当前草稿恢复尺寸，不沿用尚未应用的尺寸输入。表头在编辑中可暂时留空，保存时按共享契约校验。

模板管理负责设计列、预设行及每列固定／必填／可空规则；填写模式锁定设计，仅开放输入单元格。旧自由复制模板须显式补全规则后才能设置为场景默认，不能按已有单元格是否有值自动判断固定列。

自由复制的模板选择器只负责搜索、预览和选用，维护由独立管理页办理。应用前重新读取；停用则停止，内容变化则更新预览并要求再次确认。已有表格须确认整份替换，即使只有表头、没有数据行也须确认。选用或取消模板不直接保存业务资料。Product 等自由复制表单继续使用该流程，列规则不限制其业务草稿。

场景默认选择与模板设计分别保存，未保存的设计不能成为新默认依据。切换默认保留各自编辑版本及本地草稿，失败不能显示为已生效。来料填写的初始化及冲突重载见[来料检验](incoming-inspection-adoption.md#来料检验表单)。

模板设计、默认配置与业务编辑器分别持有本地草稿，通用读取、并发及关闭保护见[管理端架构](architecture.md)。
