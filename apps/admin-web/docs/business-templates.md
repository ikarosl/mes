# 系统模板管理

模板的内容、权限、复制及并发边界由 [Template](../../api/src/modules/template/docs/template-scenes.md)维护；JSON 表格格式由 [utils](../../../packages/utils/README.md#json-表格)维护。本文只补充管理页与业务表单共用的编辑交互。

## 编辑与使用边界

表格尺寸输入在明确确认后才改变草稿；扩展保留已有内容，缩减从末尾移除行列，涉及列名或非空单元格须确认。重新打开按当前草稿恢复尺寸，不沿用尚未应用的尺寸输入。表头在编辑中可暂时留空，保存时按共享契约校验。

模板选择器只负责搜索、预览和选用，维护由独立管理页办理。应用前重新读取；停用则停止，内容变化则更新预览并要求再次确认。已有表格须确认整份替换，即使只有表头、没有数据行也须确认。选用或取消模板不直接保存业务资料。

模板与业务编辑器分别持有本地草稿，通用读取、并发及关闭保护见[管理端架构](architecture.md)。
