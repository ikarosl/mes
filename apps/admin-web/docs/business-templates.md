# 系统模板管理

`/system/templates` 位于系统管理，路由名为 `system-templates`，缓存组件名为 `TemplatesPage`。页面准入使用 `system:templates:view`；创建和修改由后端独立鉴权，业务规则与 JSON 契约归 [Template](../../api/src/modules/template/README.md)所有。

## 编辑与使用边界

模板编辑器维护名称、启停和完整表格草稿，与业务参数录入共用 `JsonTableEditor`。用户按列数和数据行数生成表格，在表头填写必填列名；数据行数不包含表头，稳定列标识由组件生成。尺寸输入仅在确认生成或调整后改变表格；扩展保留已有列标识和内容，缩减移除末尾列、末尾行，涉及列名或非空单元格须确认，清空列同时清空行。重新打开编辑器按当前草稿恢复尺寸，不沿用上一次未生成的数量。

模板至少保留一列，允许没有预设行；表头在草稿中可以暂时留空，保存前必须填全。文本不被转换成数值、公式或脚本，校验统一消费[共享表格规范化](../../../packages/utils/README.md#json-表格)。

模板详情读取与列表筛选、分页分别持有状态。失败不能成为空白编辑依据；编辑保存使用打开时的并发版本，冲突保留草稿，不能只换用最新版本重发旧内容。取消或关闭标签需确认放弃修改，提交中禁止关闭；列表刷新不覆盖已打开的编辑器。

模板选择器与管理页分离，仅负责启用模板的搜索、分页、预览与选择；不承载模板维护。应用前重新读取，停用项拒绝使用，内容版本变化则更新预览并要求再次确认。应用所得表格复制到业务草稿，业务自身保存整份 JSON，模板没有回写资料或联动历史的能力。
