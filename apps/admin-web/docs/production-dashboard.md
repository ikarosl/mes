# 生产首页

首页保留 `dashboard` 路由及 `DashboardPage` 缓存身份。具备生产任务页面权限的账号进入[生产看板](../../api/src/modules/production/docs/dashboard.md)；其他账号显示业务菜单入口提示，不请求生产数据。

顶部工单、任务、产品、状态、关键词和日期共同确定看板范围，日期不归属某个可排序模块。排期、产出和异常共用已应用的日期；工序区的“期间流转”跟随统一日期，“当前在制”明确显示不受日期限制。业务筛选草稿由“查询”提交；日期快捷项及“应用日期”只更新已应用范围中的日期，不顺带提交业务筛选草稿。全局业务条件变化按筛选结果重新确定所选任务；调整日期保留当前所选任务。

工序区独立选择任务，候选遵守顶部已应用的业务条件，不按排期日期裁剪；局部搜索与全局关键词取交集，不覆盖全局条件。初次进入或提交业务筛选时从独立任务候选选择首项，候选为空则等待选择；排期请求失败、翻页、隐藏和排序不改变工序任务。清除选择后不由排期重新补选。点击甘特图“查看工序”只快捷切换工序区对象并显示该模块，不改变其他模块筛选；已选任务身份独立保留，不依赖当前候选窗口。

“当前在制”可勾选仅看有在制的任务；切换该条件重新核验已选任务，仍匹配则保留，否则选择匹配首项。切到“期间流转”或从甘特图快捷查看任务时取消在制限定，避免隐藏历史流转任务或阻止明确选择。该条件不改变其他图表范围；在制判定由生产看板所有者维护。

工序区切换当前／期间模式时取消旧读取，各自显示相应数量和明细；期间到站盘数及交接数量的含义由[生产看板](../../api/src/modules/production/docs/dashboard.md)维护，不展示推算的历史在制。排期与流转各占整排。图表保留自己的加载、错误、分页和统计维度；异常明细弹窗冻结打开时的分组和筛选，跨页查看卡详情继续核验工序追踪页面权限。


个人布局仅保存模块显示与顺序，按当前账号隔离在本浏览器；不保存会话凭据、业务事实或查询结果，不承诺跨设备同步。存储不可用时仍可应用本次布局，并提示无法持久保存。关闭设置弹窗不应用未保存修改。

查询、日期和布局触发用户明确操作；返回缓存页面不自动刷新。候选每次展示搜索窗口，允许继续输入定位，不全量下载业务列表；读取竞态与刷新遵守[管理端架构](architecture.md)。
