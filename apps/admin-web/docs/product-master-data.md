# 成品、基础物料与精确版本编辑

目录身份、规格参数和规格书关联由 [Product](../../api/src/modules/product/docs/product-rules.md)维护；上传及文件保留由[技术文件专题](../../api/src/modules/product/docs/technical-files.md)维护。通用候选、草稿与缓存规则见[管理端架构](architecture.md)。

## 目录与版本明细

物料版本按展开项读取，管理目录使用完整版本明细，不能用业务候选代替。展开选择只作用于当前页；刷新只更新仍展开的明细，不预取折叠项。

## 规格书草稿

选中文件即上传，但上传成功只改变当前表单的待关联文件，业务保存后关联才生效。上传中不能保存关联；失败或取消保留原附件，重新选文件才再次上传，缓存返回不自动重传。

上传结果与进度绑定本次编辑对象；关闭、切换对象或失活后的迟到结果不能改变草稿。普通标签切换仍保留已上传的文件。规格书冲突按[关联并发规则](../../api/src/modules/product/docs/product-rules.md#成品与精确物料版本规格书)处理；版本规格书须放弃旧草稿、刷新列表并重新打开，不在原草稿上仅替换核对依据。

浏览器支持的格式可预览，Office 文档下载查看。

## 规格参数与模板应用

新成品从空表开始，不预设业务列名；已存表格保留内容。表格调整及覆盖确认统一见[模板交互](business-templates.md#编辑与使用边界)。基础物料参数录入的暂停范围及旧值保留见 [Product 规则](../../api/src/modules/product/docs/product-rules.md#规格参数-json)。
