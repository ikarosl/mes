# 成品、基础物料与精确版本编辑

本文维护主数据编辑中的草稿与跨对象交互约束。业务与稳定身份规则由 [Product](../../api/src/modules/product/docs/product-rules.md) 所有；文件生命周期由[技术文件专题](../../api/src/modules/product/docs/technical-files.md)所有。通用的权限、读取竞态、缓存与关闭保护遵守[管理端架构](architecture.md)和[路由弹窗规范](route-dialogs-and-tabs.md)。

## 规格书草稿

成品以及每个精确物料版本各绑定一份规格书；基础物料不绑定规格书。新增成品、保存成品编辑及新增物料版本均须完成规格书上传，现有空关联须先补文件。版本规格书替换独立于版本编码、启停和备注，不创建新的物料版本。

选中文件后立即上传，文件名直接取原文件名，规格书不管理文件版本号。上传成功只更新当前草稿，成品保存或版本规格书保存成功后关联才生效；放弃草稿不删除已经登记的技术文件。

上传进行中不得保存关联；业务保存期间禁止关闭。关闭、切换目标或页面失活使在途上传失效，旧进度和旧结果不能写入新草稿。普通标签切换保留表单及已上传文件，返回后不自动重传；上传失败或取消后保留原附件，重新选文件才再次上传。

成品编辑和版本替换保存编辑开始时的规格书 ID，以该关联作为并发核对依据；空关联以 `null` 回传。并发失败保留用户草稿，不自动换用最新 ID 提交旧输入。成品列表刷新检测到关联变化时阻止旧草稿保存；明确重新加载才放弃草稿并采用当前关联。版本规格书冲突后须放弃当前草稿、刷新列表并重新打开，不能在旧草稿上只替换核对依据。

预览和下载消费文件元数据及既有内容接口；浏览器可直接显示的格式提供预览，Office 文档下载查看。前端显示入口不表示已经取得下载或修改权限，后端独立鉴权。

## 规格参数与模板应用

产品的规格参数保存完整 JSON 表格，含列定义和行内容；结构与校验规则由[共享 JSON 表格](../../../packages/utils/README.md#json-表格)统一维护。新产品从空表开始，用户可按行列数量生成表格并自行填写必填列名，也可应用模板，不预设业务列名。已存表格保留原有列和内容，后续调整使用[系统模板管理所述的共用表格编辑规则](business-templates.md#编辑与使用边界)。产品允许没有规格参数；生成了列则须填全列名再保存。

基础物料当前暂停规格参数录入，`MaterialFormDialog` 不提供参数表格和模板应用入口；新增空表、编辑保留已有参数的接口约定见 [Product 规则](../../api/src/modules/product/docs/product-rules.md#规格参数-json)。

产品表单提供表格编辑和应用模板入口。模板的创建、编辑与启停由[系统模板管理](business-templates.md)所有；模板选择只读取启用项，应用时再次核对内容与状态，版本已变化须重新确认预览。已有列时须确认替换整份表格，包括没有数据行的表头草稿；复制列和预设值后在本地独立编辑，通过所属业务保存接口落库，不保存模板引用、不联动后续模板修改。

共用 `JsonTableEditor` 负责行列生成、表头和文本单元格编辑及只读展示，不发请求、不决定权限或保存时机。模板与业务草稿分别由各编辑器持有，不进入全局 Store，也不写入浏览器存储。BOM 审批显示申请时冻结的表格，不回读当前模板或产品参数。
