# 工序专检与生产处理的前端约束

业务数量、事实冲销与公开能力由 [Quality 工序专检](../../api/src/modules/quality/docs/process-inspections.md) 维护，异常处置与返工由 [Production 执行规则](../../api/src/modules/production/docs/database/execution-traceability-quality.md) 维护。交付验收状态见[路线图](../../../docs/roadmap.md)。

## 登记和更正

工序专检通过独立页面办理，以任务下的具体工序为持续入口，不选择具体报工。主列表服务端按工序分页，涵盖当前可登记工序及存在检查历史的工序；关键词和仅待处理筛选在分页前作用于工序。每行展示有效合格、不合格、已处理、待处理累计、总检查次数及有效次数、最近有效检查时间。

工序详情顶部展示汇总和登记入口，下面分页列出逐次检查。登记固定使用当前工序上下文，不提供另一套全局新增与工序候选选择。检查全部冲销后，工序仍保留，显示暂无有效检查；满足执行阶段要求即可继续登记。冲销只表示单次检查状态，不能把工序标记为已冲销。单次登记、更正或冲销确认成功后返回工序详情并刷新汇总和明细，可继续办理同一工序。新增检查后明细返回第一页展示新记录，更正和冲销保留当前明细页；未知结果仍留在原编辑器核对与重试。

每次登记独立现场范围、全检或抽检、合格与不合格数、实际检查时间及凭据；数量初始留空，整数输入不按报工数量预填或封顶。全检只表示所填写的现场范围，抽检不能推算整批合格量，多次检查不累计成独立实物覆盖量。已有不合格实物复查不得重复登记为新增待办。

当前有效结果和历史分开展示。“详情 / 历史”只读展示检查信息和结果历史，不提供更正、冲销或生产跳转操作；登记、更正和冲销从工序详情的对应入口进入填写模式。已提交记录的更正通过冲销加替代保留历史，整单冲销只能在累计已处理为零时办理；更正后不合格数不得低于该单累计已处理量。生产任务结束不自动禁用既有专检的历史更正或冲销，最终资格由后端校验。冲销历史显示负向数量，保留原结果、替代关系、原因及登记人和时间。

## 处理和生产来源

质检专检页只办理登记、更正、冲销和历史查看，已处理、待处理量只读。产线在“工序执行与报工管理”的具体工序进入“专检处理”，独立弹窗按服务端分页列出该工序待处理的检查；选择具体检查后重新读取当前结果、版本和办理资格，按现场核实量及现场说明提交，数量不能超过当前待处理量。处理生成现有异常处置待办，可继续在原工序办理返工或报废，不修改报工。已处理量表示已生成生产处置单，不代表返工、报废或补料已完成，后续进度以独立的处置和返工状态为准。后续处理不重新释放已处理量。检查填错应由质检更正，专检来源不提供“驳回异常报工并退回重报”。

待处理检查与历史处理独立服务端分页，无待处理检查时仍展示历史。历史以一次真实生产处置为一行，保留实际处理数量、处置单号、处理人和时间、固定的专检单及采用结果记录引用。后续处置列展示处置结果、审核人及时间、返工单号、状态和完成时间，不在该聚合列表展开返工合格／不合格数量。历史来源不能以最新质检结果替换；处置说明会随审批改变，因此标为“当前处置说明”，不冒充首次现场说明。成功处理后刷新当前工序执行记录、异常待办、待处理检查列表，并将历史处理回到第一页；手动刷新保留两组页码、当前选择和填写草稿。历史核对不自动把未知提交认定为成功。

异常处理分组使用真实处置或返工 ID 作为展示身份；专检来源没有报工引用时明确展示专检单及结果引用，不能构造虚假报工号。专检返工结果明确标注不计普通报工汇总，合格和不合格仍按既有返工过程查看。跨页查看依据目标页面权限，未授权的来源保留文本。生产来源携带检查 ID 定位时，先解析所属工序并打开工序详情，再打开对应单次检查，不受当前明细分页是否包含该检查限制。

质检页面、菜单和路由使用工序专检查看权限；生产处理在生产任务查看权限的宿主内读取所属工序的检查依据，无需工序专检页面权限。质检工序详情上的“查看生产处理”携带任务与工序定位生产处理弹窗，先经过生产页现有任务切换与草稿保护。来源专检跨页查看仍校验目标页面权限，不为处理扩大质检菜单权限。命令由后端分别校验质检登记及生产异常管理权限，不要求页面内按钮按操作权限隐藏。

## 草稿、并发和未知结果

生产待处理列表、历史处理列表、处理详情和填写草稿分别持有状态；刷新不覆盖数量、现场说明及开始填写时的版本。版本变化时保留填写并阻止提交，明确放弃填写并采用最新依据后重新办理。处理弹窗与执行页表格并列挂载，折叠工序不会卸载填写或写意图，切换任务与关闭标签须先确认未保存草稿及未知结果。

工序汇总、检查明细、单次检查详情与结果历史分别持有读取状态；检查明细和结果历史独立分页。单次检查弹窗与工序弹窗并列挂载，关闭或切换工序须先处理单次检查草稿。关闭、切换对象、失活后旧读取不得更新当前目标。手动刷新不会替换填写内容或开始填写时的版本，远端版本改变保留输入并阻止旧依据提交，人员明确放弃后按新依据重新办理。

新增、更正、冲销和处理在首次正式提交冻结完整请求与幂等键。未知结果保留原请求并禁止修改，原样重试使用同一键；结果损坏或重试窗口结束须先核对业务结果。关闭弹窗、切换对象及关闭标签均保护草稿和未知结果，提交期间禁止关闭。切换会话清除旧意图，不写入 Web Storage。详情刷新仅用于核对，不将未知结果当作新的提交。
