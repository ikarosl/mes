# 员工工作台与工序追踪

流转、异常与终检事实由 [Production](../../api/src/modules/production/docs/database/execution-traceability-quality.md) 维护，任务开始和结束见[任务生命周期](../../api/src/modules/production/docs/database/production-termination.md)。人员目录与账号分离，人员身份由 [Identity](../../api/src/modules/identity/README.md) 维护；通用读取、草稿和未知结果保护遵守[前端架构](architecture.md)。

## 输入与现场身份

工作台的任务和本站工序决定本次扫码目标，登记人员必须人工选择。工位在管理端顶栏连接 USB 虚拟串口扫码枪，浏览器须支持 Web Serial，并通过 HTTPS 或本机 localhost 访问。按设备选择波特率（默认 9600），使用 8 数据位、无校验、1 停止位，枪端按设备手册设置回车或换行后缀。

波特率偏好保存在本浏览器。切换业务页签保留串口连接；刷新已连接的浏览器标签页后，同一账号会使用上次连接的波特率重新打开已授权的扫码枪。设备不可用时可从顶栏重新连接。主动断开或退出登录会清除本标签页的重连记录。

工序作业页在前台且办理条件就绪时，收到完整串口条码即办理一次到站和交接，与输入焦点无关。编辑中的追踪码、弹窗、在途提交和待核对结果都优先于新扫码，恢复就绪后须重扫。手输或键盘式扫码仍在追踪码框内完成，失焦只整理卡号，回车或按钮提交。两种入口共用前后端的追踪码归一化函数，仅在完整输入后还原短码。追踪页追踪码筛选只查询；完整规范卡号精确定位单卡，普通关键词片段保留模糊查询。

工作台办理操作绑定当前选择的任务与工序：只有两者均与卡的实际当前位置一致时，才开放该卡的操作入口；终检还须当前选择为任务末站。回扫已交接的历史站点只展示追踪信息，不恢复本站办理。办理弹窗期间保持所选任务、工序和人员，读取依据失效或卡位置改变时阻止新提交；未知结果继续核对原冻结请求。工作台选项不是后端权限凭据，业务资格仍由 Production 校验。同一追踪卡详情弹窗按入口提供能力：工作台打开时只读展示历史、刷新和打印；追踪卡管理显式开放原有办理按钮。工作台已有异常的处置从当前盘办理，不通过详情绕过工作站限制。

建卡、异常登记、历史异常处理和终检沿用工作台明确选择的现场人员。关联工序初始留空，按实际发现选择，与卡的实际报废工序独立。异常描述按关联工序远程搜索，可多选或逐条新增。搜索和切换工序保留已选文本与未添加输入，未指定工序时查询一般异常标签。提交时逐枚传递标签并归属最终选择的工序，未添加的输入须先添加或清空。

新异常需填影响数量并确定一种现场结果。已有待处理异常仍占用可登记量，办理时沿用原记录的工序、数量与标签。

普通处理表单不再办理关联此前报废，历史关联事实保留只读。已知涉及此前报废的旧异常须核对实物与原记录后通过保留的历史结算接口办理；超过当前盘量的异常在普通表单阻断，但数量未超限也不能证明历史实物互不重叠。此关联属于最终数量结算，不是可在处理后补填的备注；数量规则由 Production 所有者维护。

工作台并列提供现场单盘建卡和批量预生成。单盘成功后保留本任务刚使用的盘量作为下一盘默认；切换任务恢复初始值。批量填写本次分盘总量与标准每盘数量，预览完整盘、尾盘及合计，不自动套用任务计划剩余量。生成结果中的卡号与范围以服务端返回为准；打印失败从本批结果或追踪卡管理选择原卡补打，不重新建卡。

批量追踪卡终检展示当前剩余盘量并据此一次确认产出；研发任务无追踪卡，最终可用产出仍留空，须据实填写并区分零与尚未填写。最终确认前的盘量更正在原卡上办理，标签补打沿用原码。

## 单件刻码输入

编码绑定页选定任务后，当前活动页收到完整串口条码即在该任务内定位追踪卡，也可手输卡号后按回车或点“查询卡”。定位只查询；登记人员和实物刻码用于后续确认绑定。切换工作台子页时，未收齐的条码丢弃，已定位的卡与刻码输入保留在原页。页面不选择绑定工序，也不提供任务刻码开关；业务资格与统一齐码规则见[Production](../../api/src/modules/production/docs/database/execution-traceability-quality.md#单件刻码)。产品信息沿任务展示，不另行选择。

单件刻码起始号初始及整页刷新后留空，现场按实物填写。输入／粘贴 `001` 按 `1` 查重，失焦及提交时显示、保存为 `1`；刻码变化时清除旧查重结果，查重仅作提示，提交仍由服务端原子复核。绑定成功后才建议下一个整数，换卡不重置递增号码；一卡多件未绑满时保留卡号，绑满后清卡号以继续扫描，刻码仍保持下一个值。换任务清除卡对象，当前连续输入号码保留并可人工调整。递增仅属于该页面的输入状态，不是服务器号段或其他终端共享计数；全局重码由服务端拒绝，失败不递增。缓存返回保留输入。

绑定提交冻结卡、版本、人员、刻码及幂等意图；结果未知时锁定原输入并沿原请求核对，不递增或换号重试。记录列表默认当前任务，可按卡号、当前实物刻码和状态进一步筛选；未选任务时可凭全局刻码定位。卡详情与报废候选分页读取，选中报废码跨页保留，并展示本次完整选择；搜索窗口未出现已选项不表示该项失效，提交仍由后端复核。

新登记以卡实际所在站确定选码要求。前道可手动展开选择已绑定的报废件，未绑定余量不足时自动展开，终检默认展开。收起候选列表后保留已选编码，并随本笔报废提交。更正报废从单笔异常或已报废编码定位同一原记录，沿用登记时的选码规则。数量输入表示期望的总报废数，调小数量时保留勾选，由人员确认具体恢复哪一只。

批量绑定预览属于当前卡。起始号和待绑量决定初始号段，首尾均计入。移除号码只把它排除在本次提交之外，恢复可将其重新选入。手动延长结束号时保留已排除的号码。成功后按实际绑定的最大号码建议下一起始号。

下方记录列表只展示已登记且仍占号的单件。编辑草稿属于任务，按单件 ID 定位，翻页、筛选和刷新均保留。改号与清空可跨页合并保存，跨卡换绑须明确目标卡。保存前按全部草稿核对重复和换码，提交时冻结原码、目标码、卡与单件版本、人员及原因。版本冲突后保留草稿供核对，结果未知时沿原意图重试。列表内更正不推进上方连续输入的序列。

## 跨页定位与详情归属

任务页的工序入口统一进入 `/production/tracking?batchId=...`；工作台、追踪卡和报工历史使用同一份卡详情展示。追踪页可用 `cardId` 精确定位卡，`stepRecordId` 定位站点，`view=history` 定位报工历史。工序作业和编码绑定均可从当前卡跳转更正盘量，工序追踪按卡 ID 读取最新详情，确认仍可更正后直接打开该卡的更正表单。显式定位只消费一次，返回缓存标签保留原状态。

员工工作台保留 `/production/workbench`、`production-workbench` 父标签及 `ProductionWorkbenchPage` 缓存身份，页内切换工序作业和 `/production/workbench/code-binding` 编码绑定。两页独立保留输入和查询，写意图关闭保护归工作台父标签；编码绑定不新增三级侧栏菜单。

建卡、随盘异常、处理、盘量更正与终检各自冻结提交对象和版本；浏览其他卡不改写正在填写的对象。批量生成冻结任务、人员和两项数量，整批沿用一个提交意图。未知结果保留原提交内容与请求标识，重试仍使用原意图；确认放弃前须先核对相关事实。

标签仅打印 Code128 条形码及完整卡号，条纹编码使用[任务内卡号规则](../../api/src/modules/production/docs/database/execution-traceability-quality.md#任务内卡号)定义的短码，下方文字保留服务端返回的完整卡号；扫码与手输均由服务端定位原卡。不包含任务标题、盘量或人员等信息，更正盘量无需更换标签。批量打印冻结本次选择的卡号，预览中可全选或选取部分；追踪卡管理的选择只属于当前列表页，翻页或刷新时清除。预览不随其他卡浏览或列表刷新替换打印对象。

追踪卡通过[公共打印代理](../../../packages/printing/README.md)连接本工位 C-Lodop。单盘建卡并到站和批量预生成在服务端确认成功后静默提交标签，批量打印保留未到站状态。工作台和追踪页共用本浏览器及站点保存的打印机名称、毫米纸张尺寸和份数，默认 60 × 40 mm、每卡一份。预览按已保存的纸张尺寸展示整张标签，补打提交选中的原图，下载的 SVG 内嵌同一张 PNG。设备初始化与驱动首选项归属见[打印接入](../../../packages/printing/docs/lodop.md)。

常规生成入口在首次建卡前检查设置与代理可用性；已有未知建卡结果仍优先沿原请求恢复，不因打印机故障阻断事实核对。业务成功与打印提交分别呈现，打印失败不回滚建卡或再次生成编号；保留原卡供补打。代理确认只表示打印命令已提交，不能证明实际出纸；回执超时须先核对打印队列和实物，再人工决定补打，不自动重发。保存设置也不自动恢复建卡或补打。

Vite 开发模式的单盘与批量入口另提供仅生成操作，跳过打印机检查、打印占用与自动打印，供开发调试使用；生产构建不提供此入口。该操作仍调用原业务命令，单盘仍登记首站到站，批量仍只预生成；打印选择随本次提交冻结，未知结果重试沿用原选择。

任务中的产出与入库入口展示同任务产出来源、已入／待入数量及全部实际入库单。批量勾选追踪卡对应的整笔待入库产出，研发同样按产出选择，不再提供单件候选或刻码范围选择。新建目标按本次选择共用，已有目标限定本任务；有任何入库记录的产出不进入可选集合。

切换任务须清除未保存选择；未知结果沿用冻结的产出 ID、目标和请求标识。成品单号打开真实入库主单，身份与旧地址处理见[路由规范](route-dialogs-and-tabs.md#3-联动流程)；从入库明细查看生产来源进入同一工序追踪页。刻码查询以当前全局刻码定位原盘，展示其有效终检对应的“本盘入库单”；历史多单全部列出，不标为该件唯一归属，不将更正历史的旧错误码作为当前实物结果。
