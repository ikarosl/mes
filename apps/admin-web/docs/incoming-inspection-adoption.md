# 来料检验报告交互

检查事实、报告更正和打印头快照由 [Quality](../../api/src/modules/quality/docs/unified-inspection-model.md)维护，来源写入由[到货所有者](../../api/src/modules/procurement/docs/receipts.md#独立检验与分组)维护。本文只补充输入、草稿与跨页边界；通用保护见[管理端架构](architecture.md)。

## 独立入口与草稿

主页直接按到货分页，展开物料即可填写报告；已有分组归属不改变到货展示或报告入口。分组能力的停用及保留边界见 [Quality](../../api/src/modules/quality/docs/incoming-inspection-orders.md)。实际入库与采购补单均不作为打开或填写条件。

报告草稿归具体到货物料的编辑器。合格和不合格数量初值留空；规格型号无需填写，其含义与打印来源遵循 Quality 的[报告约定](../../api/src/modules/quality/docs/unified-inspection-model.md#报告内容与打印)。刷新来源或到货列表不覆盖已填写的检查项目、数量和报告头。查看历史也不替换正在填写的报告；明确选择新报告或更正时，先确认放弃脏草稿。

报告默认提供共享常量定义的五列和四个检查项目，检验工具预填“目视”，不依赖模板权限或模板读取。来料批次号只读展示当前到货单号；已保存报告继续展示其批次号快照，不从供应商批号或当前来源补值。

检查记录使用通用 JSON 表格，可直接编辑行列，也可从[系统模板](business-templates.md)复制整表内容；选用模板只修改当前草稿。浏览器 localStorage 仅保存上次成功应用的模板 ID；新报告按该 ID 读取最新启用内容，停用或读取失败时提示错误并保留初始表格，不缓存模板内容。更正与已有草稿不自动套用偏好。模板选择绑定打开时的到货物料与报告草稿，切换来源、新建或更正草稿、关闭或失活后，旧选用结果不得覆盖当前输入。新报告与更正保存遵守通用表格容量；历史超限原文仍完整查看，进入更正后明确提示需要调整，不截断内容。

保存后才能打印；历史与打印使用已保存报告的完整头快照和 JSON 表格，不拼接当前模板、主数据或未保存输入。编制、审核、批准为打印后签字空栏，不预填当前操作人或显示为线上审批。

## 到货读取与定位

到货列表独立分页，物料明细按需完整读取；明确定位和人工选择优先。通用缓存边界遵守[管理端架构](architecture.md#6-生命周期与定向刷新)，列表刷新不能清除已开报告草稿。

历史按到货行与 reportId 精确定位，先解析所属到货；页外目标按[详情定位](procurement-inbound.md#21-详情定位)独立读取。指定报告读取失败不回退到当前或最近记录；作废来源仍可查看并打印历史报告。
