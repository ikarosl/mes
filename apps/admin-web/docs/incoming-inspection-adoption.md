# 来料整批检验、定稿与入库交互

整批状态、数量算法和执行资格由[Procurement 整批定稿](../../api/src/modules/procurement/docs/receipt-acceptance.md)维护；跨模块决定见 [ADR-0015](../../../docs/adr/0015-unified-quality-quantity-semantics.md)。本文保留输入、证据和误操作边界，不重复业务流程图或公式。来料与成品使用各自契约，成品建议及待实现限制见[成品专题](finished-inspections.md)。

## 整批状态与入口

同次到货的 receipt_line 是整批办理身份；同采购行再次到货是另一明细，不可与同批计数更正混淆。round 表达办理阶段，allocation 表达正式去向及实际执行；样本不是独立处置范围。

首次及复检都先明确发起，办理覆盖全部未处置实物，样本数不能变成部分办理量。确认发起后剩余实物暂停、旧分配失去执行资格；关闭结果表单不撤销此事实。提示必须说明提交边界，不能让用户认为打开表单已暂停、关闭即恢复。

实收更正只填写本次核实总量、原因及同批确认，已入／已退只读，按服务端结果预览剩余量。确认中说明旧资格失效、回待检或零剩余办结；已拒收批次也不恢复旧拒收效力。此入口不登记新到货或损耗，普通更正不提交 ownership。

## 来料检验表单

合格／不合格数初始留空，全检与抽检的检查数量按各自契约派生，不以申报量封顶。切换方式清空数量，修改数量后重新选择结论；来料不填写成品的 coveredQuantity，不提供零量核实或实际剔除量。

申报快照只读。历史保留检验事实、结论、时间及凭据，不将“完成检查”或历史“曾放行”显示成当前可继续；不合格不自动填入实际退回／报废。明确放行仍须库管定稿，质量阻断不能用数量说明解除。

## 库管核对定稿

editor 保留当前 round、行版本及有效检验 ID，只引用本轮显式关联或服务端明确继承的结果，不提供任选历史最高值。核实剩余量时并列原实收、已处置量、原检验事实和校准后总量；建议及同检验重复引用的扣减只按所有者规则呈现，不重复授予原整批数量。

- 总量变化／全检不一致提示核对说明；抽检样本少于整批是正常情形，不能报整批差异。样本或不合格数超过核实量时不显示负建议或有效建议，要求异常依据。
- 超建议可入须明确确认依据，不能改原质检事实来消除差异；分配合计须匹配核实量，质量未放行不开放数量例外。
- 首次按原单剩余计划和建议带出待确认分配；已绑定补单通过 retainedBindingQuantity 保留采购归属并提示核对去向，不能因复检清空或恢复一次性承接资格。
- 纯分配更正带入实际未处置份额。候选缺失／读取失败保留草稿并阻止确认；计数更正影响采购份额时须显式核对并留依据。
- 补单先正式下单再承接真实到货，不再登记到货或质检；尚未落实部分保留待处理。数量例子沿[所有者文档](../../api/src/modules/procurement/docs/receipt-acceptance.md)读取。

历史展示当时轮次、检验、修订、采购分配及确认依据，不用当前值覆盖原证据，也不把历史授权当作当前执行资格。

## 人工拒收与实际执行

人工拒收数量为全部未处置实物且只读，原因必填，无需伪造 QC／正式清单。它只授权待退，不表示交接完成；旧检查或入库迟到提交应显示状态冲突，不能自动接到新轮。

撤销拒收只在当前拒收且仍有未处置量时提供，原因必填；确认说明回新轮待检、不恢复旧可入。全部已退、已入库退货、部分人工拒收均不能伪装成此操作。拒收时若既有补单归属总量与剩余不一致，依据 ownershipSources 展示各归属，人员显式填写匹配剩余的数量。

分配显示“授权去向”和“执行状态”两个维度，不能因全部入库／退回就改写原 disposition；旧轮未执行授权标失效。入库可按同一 allocation 分次，退回按具体待退分配一次确认全部余量，不创建父子范围。当前已核准例外授权不再按 G/F 拦截；旧 ID 失效不能静默换新 ID。供应商、批号及入库草稿边界见[采购专题](procurement-inbound.md)。

## 生命周期与权限

详情与历史分开、各自服务端分页，历史按需读取；Quality 查询不附加采购／生产页面权限，跨页目标独立鉴权。普通缓存切换保留草稿，父弹窗关闭／标签关闭／同页定位须保护子草稿和未知结果。

提交前重读 roundId/roundVersion、行版本及检验依据，变化或失败保留输入并停止。409 不自动换版本重试；未知结果仅按第一次 body/key 重试。通用代际及取消规则见[管理端架构](architecture.md)。待实现及验收状态统一见[路线图](../../../docs/roadmap.md)，不将文档清理视为验收。
