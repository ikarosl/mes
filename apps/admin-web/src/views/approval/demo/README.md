# 审批组件演示

开发服务启动后访问 `/dev/approval-components`，无需登录。入口只在 Vite 开发环境注册，正式构建不包含此页面及 mock 数据，不进入业务菜单。

演示页用本地、符合 `@company/contracts` 的虚构快照展示 BOM、生产结案和需求更正；业务证据与正式审批详情使用同一展示组件。可切换审批状态、打开完整详情并在内存中模拟决定，刷新或重置恢复样例，不调用审批、生产或产品 API，不写数据库或浏览器存储。

此目录的 mock 只用于人工展示验收，不作为正式测试夹具。业务规则和真实授权仍由后端所有者维护；审批组件交互约束见[管理端架构](../../../../docs/architecture.md#审批bom-与通知)，待验收事项见[路线图](../../../../../../docs/roadmap.md#审批试探验收与后续扩展)。
