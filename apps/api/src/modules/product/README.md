# Product

拥有成品与物料分类、成品、基础物料、精确版本、BOM、标准工序、工艺路线和技术文件；不拥有生产执行、库存事实或质量判定。

## 范围与边界

- 成品与基础物料使用独立身份，编码和基础单位不可变；物料名称只用于展示与搜索。
- BOM 批准后永久锁定；批量任务通过公开能力读取批准依据，研发不要求 BOM 或工序。
- 路线发布后不原地修改；批量任务冻结路线、工序与 SOP，不用当前配置覆盖历史快照。
- 跨模块通过 [`public.ts`](public.ts) 读取稳定契约或核对用途资格；历史展示引用不授予采购或领料资格。
