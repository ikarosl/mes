# 来料检查报告与来源协作

Quality 只记录实际来料检查及报告内容，Procurement 拥有到货来源，Inventory 拥有实际库存。每份报告绑定具体到货明细；没有开始检验、处理轮次、复检状态或放行结论。仓库可以先入库后登记报告，未检查或存在不合格数均不由 Quality 阻断入库。到货及仓库处理规则见 [Procurement](../../procurement/docs/receipts.md)，物理约束见[数据库设计](database.md)。

## 登记与修订

每条到货明细首次填写为登记，之后补充或纠正内容均修订当前报告；不再并列创建多份独立检查报告。报告保存方式、合格数 G、不合格数 F、检验时间、可选异常说明和凭据，以及完整检查表格。方式为全检或抽检；G/F 是该版报告记载的实际检查数量，N=G+F 必须为正整数且不超过公共单条数量上限，不推导到货量、整批合格量、可入量或采购履约量，各版数量不累计。

已保存报告不可更新或删除。当前报告按记录创建时间、ID 倒序取首条，与补录的检验时间无关；有报告后，保存必须以 `previousRecordId` 引用当前报告，并填写修订原因。修订追加完整内容、独立报告编号及前驱引用，原报告保留为历史，不改变库存或到货事实。一份报告只能有一个直接修订后继；不能从历史记录另开分支，也不能再次按首次登记保存。

“登记／修订”描述记录的产生方式，“当前／历史”描述现在采用哪份内容；当前不表示质量放行或审批通过。已有多个无前驱记录时保留其原文、编号和关系，仍按相同顺序选当前报告，其他标为历史登记；不补造修订原因或前驱。后续只接续当前报告。

检验凭据与异常说明允许为空。报告中的检验结果为人工填写的表格文字，不另建通过／不通过代码、处置状态或审批流。持有 Quality 登记权限的仓管或其他人员均可登记，不按岗位名称增加限制。

## 报告内容与打印

报告保存服务端报告编号、生成时材料名称和物料版本编码、供应商、采购单号、到货单号、批次号和有效期。来源身份由真实到货明细 ID 确定；名称等内容快照只用于保留当次报告，不能作写入资格或新增业务身份。报告号按 `incoming_inspection_report` 类型在业务事务内[统一取号](../../../../docs/business-numbering.md)，用户补录的检验时间不决定编号日期。

报告中的“规格型号”对应物料版本，显示与打印均取报告保存的 `materialVariantCode`，不接收人工填写。旧报告的手填规格原文仅作为历史字段保留，新报告不再写入该字段。新报告的打印批次号由可信来源的到货单号生成，不接收人工批号；已有报告按原批次号快照读取和打印。有效期保存纯日期。

检验记录保存完整 `inspectionDetails: JsonTableData`，包含列定义及有序数据行，至少有一列和一行数据；结构、容量与单元格原文保留由共享 [JSON 表格规范化](../../../../../../packages/utils/README.md#json-表格)负责。共享常量提供五列、外观／包装要求／材料证明／数量四个初始项目，可自由编辑列及行。使用系统通用模板时复制当前完整 JSON，保存后的报告独立于模板，不保存模板身份、动态列规则或审批关联；模板后续编辑或停用不改变报告。

打印按精确报告 ID 读取保存内容，标题为“进料检验报告”，检验日期来自真实检验时间。页脚编制／审核／批准只保留打印签字空栏；系统不保存签字人、签核状态或审批动作。[质检分组主单](incoming-inspection-orders.md)已停用，保留的关系和号码不决定报告编号、内容或打印历史。

## 事务与权限

HTTP 入口由 Procurement 场景编排，后端独立校验 `quality:inbound-inspections:inspect`。Procurement 在同池事务中锁定到货主表和明细，核验来源存在、明细归属与未作废后，向 Quality 公开命令提供可信来源快照。Quality 不查询或锁定采购表，在来源锁内以当前读核验本模块最新报告与提交前驱，拒绝重复登记和过期修订；报告、日序号、成功审计和 HTTP 幂等结果一起提交。无活动事务时拒绝记录。

同一来源的保存与作废由 Procurement 的来源锁串行处理。作废后不能登记或修订，既有报告保留并可按 Quality 查看权限读取和打印；不伪造失效结果、不删除报告。既有分组关系不改变报告来源或保存资格。

报告历史按到货明细服务端分页，按记录创建时间与 ID 倒序；同一响应的记录总数、当前报告 ID 和当前页明细共享读取快照，当前报告 ID 不随页码变化。精确报告读取不受既有分组、分页、入库状态或来源作废影响。工作列表的记录总数包含登记与修订的全部历史，不代表独立检查次数；当前报告摘要采用上述登记顺序，不成为入库依据。HTTP 路径与到货读取由[到货查询](../../procurement/docs/receipt-queries.md)维护。
