# 成品入库协作

成品实际产出由 Production 的[最终确认事实](execution-traceability-quality.md#production_tracking_output)扣除明确撤销的记录后唯一提供。批量卡在末站登记现场人员并显式确认，数量由锁定的当前剩余盘量生成；全部报废无产出或入库。研发可以多次手填实际产出，零数只保存确认事实。终检只形成待入库产出，不写库存；实际产出不受任务或工单计划数量限制，不另设补产登记。

仓管按同一任务、同一成品勾选一条或多条正数待入库产出，整笔确认入库；批量按追踪卡对应的产出选择，研发按实际产出选择。每条新产出整量办理一次，不在入库时挑选单件刻码或拆分盘量。所选记录可以共建一个新批次，或追加至本任务已有且身份、单位、状态符合要求的成品批次。任务已结束不阻止其有效产出入库，计划不限制实际数量；包装盒不建模，换包装不改变原追踪卡来源。

Production 在来源锁内核验每条产出有效、同源、正量且没有任何实际入库，再通过 Inventory 公开能力办理。HTTP 统一接收产出 ID，单件 ID 不再作为入库选择。Inventory 拥有公共入库单／明细、批次与库存流水；一张入库单逐产出保留明细及 production_output_id，多条明细可以指向同一批次。来源校验、入库、流水、审计和幂等结果同事务提交。

任务及工单同时展示有效终检产出、已入库、待入库数量。已入库取关联来源的已完成入库明细及匹配原始正流水，待入库为有效产出减已入库；不从当前库存余额倒推。产出保留全部实际入库单供历史查询，已有入库即不能再次入库或撤销。未入库撤销沿[追踪卡规则](execution-traceability-quality.md)保留原确认及撤销事实；库存后续补差不改原产出或原始入库事实。

刻码用于定位原追踪卡，入库追溯沿该卡的有效产出查看“本盘入库单”；不再保存或宣称每件独立分配到某张入库单。历史一盘已有多笔入库时，完整展示这些真实单据，不合并、删除或伪造唯一单据。历史无码终检继续按原有效产出整笔办理，不补造单件身份；现行齐码规则只约束新终检。

整笔入库的来源校验、既有单据核对及降级条件由 [Inventory](../../../inventory/docs/database/inventory-ledger-and-inbound.md#整笔入库数据升级)维护。

身份、锁序和回滚遵守[跨模块规则](cross-module-rules.md)与[库存协作](../../../../../../../docs/inventory-extraction-design.md)，事实结构仅在各所有者维护。
