# 生产业务流程

产品资料和物料库存准备完成后，下达工单、创建任务并配置本任务物料。批量任务显式选择路线、冻结各工序与 SOP，研发不配置路线或 BOM。详细规则与逐表结构由[数据库专题](database/README.md)维护。

批量任务的办理顺序是：完整确认初始 BOM 需求 → 分配和分次领料 → 管理员明确开始任务 → 建卡并打印每盘标签 → 逐站扫码 → 末站质量人员显式确认可用产出并同事务入库 → 管理员人工结束任务。首次扫码仅到站，下一站扫码自动完成前站交接报工，登记人员归属不因下一站人员变化而改写。

领料与开工独立，有未领物料时说明原因可以开始；异常或物料损耗不自动补料。额外用料由管理员独立提需，正式需求数量更正仍经保留的审批替代链，实际履约只由确认领料产生。

普通、随机抽检及终检发现统一登记随盘异常。暂停异常阻止继续流转，全部异常处理完成后才能最终确认；中间检验工序采用普通扫码操作。末站盘量供核对，不作为最终产出事实，最终可用数量必须由质量分组人员明确填写，允许零，正数直接入库。现场登记人与登录账号分别留存，登录账号 RBAC 继续授权各项操作。

研发按任务级明确开始、手工提需和最终产出确认办理；质量人员可确认一次正数或零产出，正数同事务入库。研发或批量任务都可以短产、零产或提前结束；结束原子取消待领料单、释放预留、关闭剩余需求、作废未完卡，已经形成的事实保留。

任务不会由数量自动完成。工单由管理员另行复核所有任务已结束及最终产出是否足量，足量可确认完工再归档，不足可以填写原因提前关闭。真实余料可沿原分配退回原库批，不回退需求履约或原产出。
