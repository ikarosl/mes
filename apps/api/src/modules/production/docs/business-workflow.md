# 生产业务流程

产品资料和物料库存准备完成后，下达工单、创建任务并配置本任务物料。批量任务显式选择路线、冻结各工序与 SOP，研发不配置路线或 BOM。详细规则与逐表结构由[数据库专题](database/README.md)维护。

批量任务的办理顺序是：完整确认初始 BOM 需求 → 分配和分次领料 → 管理员明确开始任务 → 预制卡后逐站扫码，或首工序现场单盘建卡即到站 → 末站登记现场人员并显式确认待入库产出 → 仓管勾选同任务产出合批入库；管理员独立结束或恢复任务。标签按需打印或补打，不触发建卡。首站仅记到站，下一站扫码自动完成前站交接报工，登记人员归属不因下一站人员变化而改写；建卡、拆盘与编号边界见[追踪卡执行](database/execution-traceability-quality.md)。

领料与开工独立，有未领物料时说明原因可以开始；异常或物料损耗不自动补料。额外用料由管理员独立提需，正式需求数量更正仍经保留的审批替代链，实际履约只由确认领料产生。

普通、随机抽检及终检发现统一登记带影响数量的随盘异常，任何未结异常都阻止整盘后续流转。异常只结算一次，返修、实际新增报废和关联已有报废共同解释影响数量，只有新增报废扣卡量；具体重叠与并发边界见[追踪卡执行](database/execution-traceability-quality.md#随盘异常)。全部异常关闭后，中间检验工序仍采用普通扫码操作，末站登记现场人员并显式确认，服务器以当前剩余盘量形成待入库产出；整盘报废保留历史，不生成产出或库存。现场登记人与登录账号分别留存，登录账号 RBAC 继续授权各项操作。

研发按任务级明确开始、手工提需和最终产出确认办理；登记现场人员后可多次确认正数或零产出，正数待仓管入库。研发或批量任务都可以短产、零产或提前结束；结束原子取消待领料单、释放预留、关闭剩余需求，保留未完卡的工序和数量。恢复后继续执行，物料安排按当前情况重新办理，已有事实不倒退。

任务不会由数量自动完成。工单由管理员另行复核所有非取消任务已结束，明确完工或填写原因提前关闭，产出与计划差额仅供核对。真实余料可沿原分配退回原库批，不回退需求履约或原产出。
