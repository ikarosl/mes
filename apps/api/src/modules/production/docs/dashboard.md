# 生产首页只读看板

Production 拥有排期、工序流转、产出与异常的展示汇总。数据只读现有工单、任务与追踪事实，不保存汇总表，不改变计划、流转、异常或库存办理资格。基础数量及纠错语义仍由[工单与任务](database/work-orders-and-batches.md)和[追踪卡执行](database/execution-traceability-quality.md)维护。

## 权限与查询边界

`/api/production/dashboard` 下所有接口独立要求 `production:tasks:view`，仅有首页权限不能读取生产看板。个人布局不授予角色或数据权限。候选 `/options/work-orders`、`/options/tasks`、`/options/products` 仅供该看板消费，采用服务端分页窗口；工单及产品来源于已有工单快照，任务来源于已有任务，不替代主数据或命令候选。

筛选支持精确工单、任务、产品、当前任务状态，以及工单号／任务号／产品快照关键词。候选局部搜索与上述业务范围取交集，不覆盖全局关键词，也不受排期日期限制。排期、产出分组、异常排行及事实明细均服务端分页；排期按工单 ID 降序、任务 ID 升序排序，同一工单可以跨页，前端不能把本页任务当作工单完整集合。未创建任务的工单保留一条排期。候选窗口缺项不表示已选对象失效。仅看有在制的候选要求任务存在 `in_progress` 追踪卡且当前站属于该任务冻结工序，不依赖任务状态或开始日期；与工序在制盘数口径一致，零余量但待处理异常的在制卡仍保留。

## 统计口径

- 日期范围为北京时间自然日，包含起止日，最长366天。排期纳入计划区间或实际执行区间与窗口相交的任务，计划起止缺项的记录仍展示且标明未完整设置；不猜造日期。父工单条使用其自身计划日期，不以当前页任务推断。实际条从真实开工到结束／取消时间，未结束则截至当前时间。有计划结束日期且未取消的任务，从计划结束次日起按自然日计算延期。已结束任务按实际结束日计算，其余任务按当前日计算。
- 工序的“当前在制”是选中任务的当前情况，不受日期窗口限制，不是历史回放。工序只使用该任务冻结快照；`in_progress` 卡当前余量计入所在工序，未到站卡量单独列示，作废、整盘报废和已完成卡不计在制。停留按原到站时间计至读取时刻，包含等待、非生产时间及任务暂停，不认定实际工时或自动超时。已交接数量保持历史快照，不能跨站相加成为最终产出。流转摘要在同一只读用途事务中读取，明细独立分页，刷新之间允许反映新的业务进度。
- 工序的“期间流转”按所选任务、北京时间自然日窗口读取冻结工序及追踪事实。到站盘数按 `production_tracking_visit.arrived_at`，完成交接盘数及交接量按 `completed_at` 与 `reported_quantity` 快照分别统计；一条到站记录在同一工序只计一盘，期间到站与期间完成交接不要求属于同一批卡。没有到站数量快照，不拿卡当前数量推算历史到站量，也不以到站减交接还原历史在制。期间明细按“到站或完成交接落入窗口”纳入，标明期间发生的动作，交接量只在完成时间落入窗口时展示。到站登记人员使用 visit 快照。
- 期间流转保留后来作废／报废卡已经发生的到站和交接事实；有效产出按确认日期统计并排除撤销，异常按发现日期统计并排除作废。撤销产出不抹掉既有交接快照，两者不强求相等；各站交接量不跨站相加作为最终产量。工序异常按冻结工序归属，任务异常汇总还包含未指定工序的记录。期间汇总在同一只读用途事务中读取，明细独立分页。
- 按任务的产出对比以排期窗口选任务，展示完整任务计划和累计有效产出，排除取消任务；按日则以产出确认日期选事实，不虚构每日计划。撤销产出从有效数量排除；按产品身份及历史单位分组，不汇成跨产品总量。产出不等于库存，未入库及库存补差均不改写该指标。
- 异常按发现日期进入窗口，排除已作废异常；更正数量不增加发现次数。按原因以原文逐字相同的标签归组，同一异常在同一原因只计一次，一条异常可在多个原因出现；排行合计不等于异常条数或不良件数。按工序以冻结工序名称逐字归组，跨任务及路线合并同名工序，未指定工序的异常单独归组。明细沿所选分组、业务条件和日期筛选读取真实异常，逐条显示来源任务和追踪卡。

本看板不推导理论产能、产能利用率、人员效率、机器停机或不良率；查询结果不用于写入资格校验。
