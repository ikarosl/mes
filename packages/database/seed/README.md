# 系统基础数据

本目录只保存可重复执行、且不含凭证的运行基础数据。当前包括内置 `admin` 角色、通配权限 `*` 及其关联。

权限目录仍随对应功能的 migration 发布，因为权限编码与应用代码、路由和接口版本绑定。管理员账号及密码由 `db:bootstrap-admin` 使用环境变量单独初始化；集成测试业务数据继续由各测试 fixture 创建和清理，不得放入本目录。演示或联调样例数据不属于本目录职责，统一放在独立的 `packages/database/demo` 目录，由显式命令 `pnpm db:seed:demo` 加载，绝不进入 `db:init`、生产部署或 CI 自动执行链路。
